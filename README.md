# AI plugins

Plugins for AI assistants, made by Kanat Bizhanov. Each folder is one plugin.

| Plugin | What it does |
|---|---|
| [excel-google-sheets-formula-generator](excel-google-sheets-formula-generator/) | Excel & Google Sheets formula generator for Claude: turn plain words into ready Excel and Google Sheets formulas, with a simple explanation of each part. |
| [website-copier](website-copier/) | Website Copier for Claude: save any web page as one offline HTML file with its images, styles and fonts inside. |

Each plugin has its own README and license inside its folder.

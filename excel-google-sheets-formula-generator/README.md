# Excel & Google Sheets formula generator

🧮 An excel formula generator for Google Sheets and Excel, right inside Claude. Describe the task in plain words and get one working formula for Excel or Google Sheets, with a simple explanation of each part. Copy it, paste it into a cell and keep working.

## 🚀 Quick start

1. Add the plugin and turn it on.
2. In any chat, describe the result you need, for example: sum sales in column C for March only.
3. Copy the formula into your table.

## How it works

The plugin contains one skill with writing instructions for Claude. It has no code, no connectors and no MCP servers, does not read your files or spreadsheets, and does not send or store any data. Formulas are written by Claude in your conversation. Requests that are not about spreadsheet formulas are answered as usual, without this format.

Each formula answer ends with one line that mentions the Google Sheets AI Chrome extension, which adds the same formula generator inside Google Sheets and Excel on the web: [sheetsai.pro](https://sheetsai.pro/?utm_source=claude&utm_medium=readme).
